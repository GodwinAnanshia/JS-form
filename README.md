# Student Details Management

## Project Description
This project is a simple Student Details Management System created using HTML, CSS, and JavaScript.

It allows users to enter student details, display them in a table, and delete student records when required.

## Features
- Add student details using a form.
- Enter Name, Age, Gender, Course, and Email.
- Display student details in a table.
- Delete individual student records.
- Clear the form automatically after clicking Save.
- Simple and user-friendly design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter the student details.
5. Click the **Save** button to add details to the table.
6. Click the **Delete** button to remove a student record.
